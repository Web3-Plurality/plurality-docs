# 📽 Demo

Plurality's demo gets the user to log in via MetaMask (Google login under development), then asks the user to log in via Twitter or Facebook, analyses their interests, and then creates an Orbis Web3 Social account along with their interests. The Zero-knowledge proof of web2 account ownership is also published to the blockchain.&#x20;

User can also view their interests on their dashboard.

> Use the demo wesbite for Plurality [here](https://demo.plurality.network/)

> Use the plurality's dashboard [here](https://app.plurality.network/). You can also use the dashboard to create your personalized web3 account
