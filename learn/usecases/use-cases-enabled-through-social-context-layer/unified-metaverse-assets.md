# 🎮 Unified Metaverse Assets

Today, there are multiple metaverse platforms like Decentraland, Sandbox, etc. There are also many different gaming platforms. However, the assets generated on these platforms are not always interoperable. You need to create individual contexts on these platforms and cannot use your assets from one platform in another.&#x20;

Profiles can act as a generic standard to allow for interoperability between assets on various platforms.&#x20;
