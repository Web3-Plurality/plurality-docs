# 🦸 User data explorer

User's data is stored in different streams (one for each data source & data schema) in an encrypted fashion. Only the user has the means to decrypt it. The underlying tech used for this feature is Ceramic data streams.

The currently supported explorer for viewing details of any user's data stream is [cerscan](https://cerscan.com) &#x20;

If you want to view details of your own data, you can also directly view it in [dashboard](https://app.plurality.network), where it is shown in decrypted form.&#x20;
