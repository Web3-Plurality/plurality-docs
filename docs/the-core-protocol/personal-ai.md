# Personal AI

Every Smart Profile will be associated with a Personal AI Agent that can respond to queries using the data in this smart profile. \
\
Some examples would be:&#x20;

* What topics is this user most interested in?
* Based on user's past activity, would they prefer X or Y?
* How should the UI be adapted according to this user? What mode? What font size? etc.&#x20;

Moreover, this agent can also takeover some tasks from the user e.g.

* If an NFT collection gets listed on this platform and is in a category I am interested in and is available under 10$, buy it.
* If my favorite artist lists tickets to a concert and the ticket price is under 100$, buy it.&#x20;
