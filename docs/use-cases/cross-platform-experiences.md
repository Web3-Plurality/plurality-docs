# Cross Platform Experiences

Plurality’s product (Reality Spectrum Matrix) can allow for cross-platform experiences. Using a single profile, multiple platforms can be connected and user’s can use RSM to jump between different URLs on platforms using the profile as a single hub.&#x20;

{% hint style="info" %}
Check out the [demo](https://app.plurality.network) that does this in the fashion area
