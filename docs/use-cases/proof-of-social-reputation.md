# Proof of Social Reputation

Proof of social reputation is a less stringent form of sybil resistance that can show whether a certain account is reputed enough in a certain thing. For example, when buying something on Amazon or Etsy, we see the seller’s reputation. Similarly, when placing an order on Fiverr, we see the ratings of the seller to decide whether we have to place an order or not.&#x20;

Social reputation shows how reputed a person is in a certain context. This data can be sourced from the user's existing profiles.
