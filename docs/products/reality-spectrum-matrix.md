# Reality Spectrum Matrix

The Reality Spectrum Matrix (RSM) is a tool that interconnects the existence and experiences of a user across multiple platforms using the user's Smart Profile.

With RSM, you can create incentive mechanisms to drive users through cross-context game loops between social, game, metaverse and e-commerce touchpoints.

RSM's first application is in [DFDC's Fashion Week Connect](https://www.dfdc.xyz/) where it's used for creating campaigns across multiple platforms at the same time.

Want to test it out? Go [here](https://app.plurality.network/).
